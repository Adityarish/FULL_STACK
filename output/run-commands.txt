EXPERIMENT 12 - Book Store (React + Express + MongoDB)

Step 1: Start the installed MongoDB service:

brew services start mongodb/brew/mongodb-community@8.0

Open MongoDB Compass and connect using:
mongodb://localhost:27017

Database: BOOKSTORE-2026-27
Compass is the database viewer; the MongoDB service must also be running.
The server's .env file is already configured for this local database.

Step 2: Start the backend in one terminal:

cd /Users/adityasingh/FULL-STACK/exp-12/server
npm start

API: http://localhost:5000/api/books

Step 3: Start the frontend in a NEW terminal:

cd /Users/adityasingh/FULL-STACK/exp-12/client
npm start

Browser: http://127.0.0.1:5182
