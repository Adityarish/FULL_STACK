# Experiment 12 Book Store

This experiment contains an Express and Mongoose API plus a React client.

## Run

1. Start MongoDB locally and connect MongoDB Compass to `mongodb://localhost:27017`.
2. In `server`, run `npm install` and `npm start`.
3. In `client`, run `npm install` and `npm start`.
4. Open `http://127.0.0.1:5182`.

The API uses the `BOOKSTORE-2026-27` database and serves books at `http://localhost:5000/api/books`, as in the supplied document.
